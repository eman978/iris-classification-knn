# Project 2: Data Classification Using AI

**DecodeLabs — Artificial Intelligence Engineer Track**

A supervised learning project that builds, trains, and evaluates a K-Nearest Neighbors (KNN) classifier on the Iris dataset, complete with a Jupyter notebook analysis and a deployable Streamlit web app.

---

## Project Structure

```
decodelabs-project2/
├── app.py                     # Streamlit web app for live predictions
├── requirements.txt           # Python dependencies
├── .gitignore
├── .streamlit/
│   └── config.toml            # App theme configuration
├── notebooks/
│   └── Project2_Data_Classification_Using_AI.ipynb   # Full analysis notebook
├── src/
│   └── train_model.py         # Script to train and save the model
└── models/
    ├── knn_model.pkl          # Trained KNN model (generated)
    └── scaler.pkl             # Fitted StandardScaler (generated)
```

## What This Project Covers

- Loading and exploring the Iris dataset (150 samples, 3 classes, 4 features)
- Feature scaling with `StandardScaler`
- Train-test split (80/20, stratified)
- Choosing the optimal K using the elbow method
- Training a K-Nearest Neighbors classifier
- Evaluating results with a confusion matrix, precision, recall, and F1 score
- Deploying the trained model as an interactive web app

## 1. Run Locally

```bash
# Clone the repository
git clone https://github.com/<your-username>/decodelabs-project2.git
cd decodelabs-project2

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Train the model (generates models/knn_model.pkl and models/scaler.pkl)
python src/train_model.py

# Run the notebook
jupyter notebook notebooks/Project2_Data_Classification_Using_AI.ipynb

# Run the web app
streamlit run app.py
```

The app will open at `http://localhost:8501`.

Replace `<your-username>` with your actual GitHub username, and make sure the repository you created on GitHub is empty (no README/license added there) to avoid merge conflicts.

**Note:** `models/knn_model.pkl` and `models/scaler.pkl` are generated by `src/train_model.py`. Run that script once before pushing so the deployment app has the model files it needs, or let the deployment platform run it during setup (see below).

## 3. Deploy for Free (Streamlit Community Cloud)

1. Push this project to GitHub (see step 2 above).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with your GitHub account.
3. Click **"New app"**.
4. Select your repository (`decodelabs-project2`), branch (`main`), and set the main file path to `app.py`.
5. Click **"Deploy"**.

Streamlit Cloud will install everything from `requirements.txt` automatically. Since `models/*.pkl` should already be committed to the repo (from running `train_model.py` locally before pushing), the app will load them directly — no extra setup needed.

If you prefer not to commit the `.pkl` files, add this line near the top of `app.py`'s `main()` function as a fallback, or simply run `train_model.py` locally once and commit the resulting `models/` folder before deploying.

Your live app URL will look like:
`https://<your-username>-decodelabs-project2.streamlit.app`
